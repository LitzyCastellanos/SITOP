# SITOP — Sitio Web Oficial

Sitio web institucional de **SITOP**, empresa hondureña de ingeniería civil especializada en servicios de construcción, topografía y supervisión de obras.

🌐 **Sitio en vivo:** [sitophn.com](https://sitophn.com/) *(próximamente)*

---

## 📁 Estructura del proyecto

```
sitop-web/
│
├── index.html          # Página de inicio
├── nosotros.html       # Quiénes somos
├── servicios.html      # Servicios ofrecidos
├── proyectos.html      # Galería de proyectos
├── contacto.html       # Contacto
├── style.css           # Estilos globales
├── script.js           # Lógica e interactividad
└── img/                # Recursos de imagen
```

---

## 🛠️ Tecnologías utilizadas

| Tecnología    | Uso                          |
|---------------|------------------------------|
| HTML5         | Estructura del sitio         |
| CSS3          | Estilos y diseño responsivo  |
| JavaScript    | Interactividad y animaciones |

---

## 📌 Páginas

- **Inicio** — Hero slider, servicios destacados, proyectos recientes y sección de contacto.
- **Quiénes somos** — Historia de la empresa, misión, visión y valores institucionales.
- **Servicios** — Catálogo completo de servicios ofrecidos.
- **Proyectos** — Galería con filtros por categoría y visualización tipo mosaico con modal.
- **Contacto** — Formulario de contacto y datos de la empresa.

---

## 🚀 Despliegue

El sitio será desplegado en **Netlify** con dominio personalizado adquirido en **GrupoHost**.

---

## 🏢 Sobre SITOP

SITOP es una empresa hondureña de ingeniería civil comprometida con la calidad y precisión en cada proyecto. Ofrece servicios integrales que van desde la topografía y planificación hasta la construcción y supervisión de obras.
