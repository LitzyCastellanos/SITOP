# SITOP — Sitio Web Oficial

Sitio web institucional de SITOP, empresa hondureña de ingeniería civil con servicios de construcción, topografía y supervisión de obras.

## 🌐 Sitio en vivo (proximamente)
[sitophn.com](https://sitophn.com)

## 📁 Estructura del proyecto
├── index.html
├── nosotros.html
├── servicios.html
├── proyectos.html
├── contacto.html
├── style.css
├── script.js
└── img/

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript vanilla

## 📌 Páginas
- **Inicio** — Hero slider, servicios destacados, proyectos y contacto
- **Quiénes somos** — Historia, misión, visión y valores
- **Servicios** — Catálogo de servicios ofrecidos
- **Proyectos** — Galería con filtros por categoría y modal tipo mosaico
- **Contacto** — Formulario y datos de contacto

## 🚀 Despliegue (proximamente)
Desplegado en **Netlify** con dominio personalizado adquirido en GrupoHost.
